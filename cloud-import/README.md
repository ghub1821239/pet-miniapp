# 示例帖子导入

这里保存了课程演示使用的 24 条帖子数据。只运行根目录的算法演示命令时，不需要导入数据库或下载图片。

## 文件

- `posts-import.json`：JSON 数组格式。
- `posts-import.jsonl`：每行一条记录的 JSON Lines 格式。
- `image-file-map.json`：原开发环境中的图片文件名与 fileID 对照。
- `db-commands/`：开发时保留的分批导入及清理命令。`delete-posts.json` 是删除命令，不属于常规导入步骤。

## 导入自己的云环境

1. 在云存储中上传自己准备的帖子图片，取得对应的 fileID。原说明中引用的电脑图片目录不在仓库内，不能直接使用。
2. 将导入文件中的旧 `cloud://` 图片地址替换为自己的 fileID；本地示例数据 `data/mockPosts.js` 也包含旧地址，使用本地示例时需要同步替换。
3. 在自己的云数据库中创建 `posts` 集合，按控制台支持的格式导入 JSON 或 JSON Lines 文件，两者选其一。
4. 检查记录数量和图片显示。重复导入前先核对已有记录，避免生成重复帖子。

这些数据用于演示，不是真实用户的使用记录。原环境图片是否仍可访问不影响纯算法演示，但会影响小程序中相应图片的显示。
